# Aqua Rush 联机实现计划与 Cloudflare 方案

基于上游 main：94b3e11d32d234eeba4fd4c0316af0d2993732f9。
功能分支：feat/online-multiplayer。Fork：Aimer779/aqua-rush。

## 已确定的范围

用户已确认先按房间码进组，并选择部署到自己的 Cloudflare 账户。
首版为 2–4 人互联网竞速，复用两条赛道、三圈、检查点、漂移、奖励门和碰撞。
保留 Quick Race 与 Time Trial，联机成绩不写入单机计时纪录。
不加入公开匹配、账号、全球排行榜、观战或 AI 补位。

## 部署与架构

前端和服务端部署到同一个 Cloudflare Worker 域名：

- Workers Static Assets 托管 Vite 构建后的网页。
- Worker 处理建房与连接请求，每个房间码映射到独立 Durable Object。
- Durable Object 持有比赛真值，负责玩家席位、准备、加载、模拟、结果和重连。
- 使用 SQLite 类型的 Durable Object；只保存房间有效期元数据，比赛状态驻留内存。
- 客户端使用同源 HTTPS/WSS，无需 VPS、单独的 Pages 项目或跨域配置。

采用 Cloudflare 原生 WebSocket 和 Durable Objects 后，不再引入 Colyseus 常驻 Node 服务。
开发与部署使用锁定版本 Wrangler，保持现有 npm/package-lock.json 工作流。

## 游戏规则

1. 玩家填昵称并建房，分享八位房间码；其他玩家输入房间码加入。
2. 房主选择赛道，所有玩家准备，至少两人后才能开始。
3. 全员加载完成后，由服务端统一倒计时；加载超过 30 秒返回大厅。
4. 比赛开始后禁止新席位中途加入；已掉线席位可在 15 秒内重连。
5. 房主只管理大厅，退出不会停止其他人的比赛；管理权转给在线玩家。
6. 暂停只打开自己的菜单并清空操作；R/Enter 不允许重置全场。
7. 救援由服务端定位到最后合法检查点，限制频率，不补充能量或增加进度。
8. 每名玩家独立完赛；第一名到达后给予其他人 60 秒，超时记 DNF。
9. 整局最多十分钟模拟时间；全部完赛/退赛后统一结算。
10. 结算后房主可返回大厅，重新准备；单机纪录与联机成绩隔离。

## 实现结构

- server/RoomSession.ts：与传输解耦的房间状态机，时间由调用方传入，便于确定性测试。
- server/RaceRoom.ts：WebSocket、消息限速、固定步长调度、连接和资源回收。
- server/worker.ts：API、同源校验、建房限速、房间路由和网页托管。
- src/shared/OnlineSimulation.ts：组合现有船只、波浪、碰撞、门和检查点规则。
- src/shared/BoatState.ts：包含内部计时器、垂直速度及波浪反馈的完整可恢复状态。
- src/network：连接重试、房间 UI、本船预测校正、远端插值。
- Game：将稳定网络 ID 和船型槽位映射到现有本地渲染对象。

代码检查表明现有运动逻辑可在无 DOM/WebGL 环境运行，因此保留 Three.js 数学与
变换对象，仅跳过几何资源和全局 AI 注册。单机和服务端继续复用同一份运动规则。

初始模拟为 60 Hz，快照为 20 Hz。客户端只提交有序输入；服务端不接受位置或完赛声明。
本船恢复服务端确认状态后重放未确认输入；其他船按快照插值。
重连发送完整状态，事件按编号去重；碰撞和奖励判定均由服务端负责。

## 分阶段交付

1. 建立原始构建基线，补齐共享状态与无渲染模拟，验证单机行为。
2. 打通两客户端从建房、准备、开赛到结束的完整流程。
3. 补齐四人、两赛道、独立完赛、结算和再来一局。
4. 验证重连、暂停、非法消息、过期输入、加载超时和房间回收。
5. 本地 Cloudflare 运行时验证通过后部署新 Worker，并检查真实 HTTPS/WSS 访问。
6. 审阅任务差异并提交功能分支，推送 fork，向原仓库 main 提交 PR 由作者评审合并。

## 验证要求

- 前端构建与 Worker 类型检查分别通过。
- 房间权限、人数、准备/加载屏障、重连期限、计时与回收采用受控时钟测试。
- 完整状态恢复后的驾驶必须可重复；测试 50/100/200 ms RTT 和受控抖动下的校正边界。
- 两个浏览器验证真实房间码加入、开赛、移动、个人暂停和刷新重连，覆盖桌面与移动端。
- 四个真实 WebSocket 客户端在两条赛道自然驾驶三圈，核对全部客户端最终名次与时间。
- 回归现有存档、单机玩法、输入、视觉及生产预览性能测试。
- 视觉失败与未修改上游在相同环境比较；仅更新确认由本次 UI 改动产生的基线。
- 部署后验证健康接口、网页和真实房间，不将本地模拟器通过视为线上验证。

## 运行边界

大厅/结算闲置五分钟后关闭，房间最多存在一小时，届时清除元数据。
服务重启、部署或运行时回收可能中断内存比赛；客户端提供重连/过期反馈。
正在比赛的房间持续占用运行时间，会消耗 Cloudflare 请求与时长额度。
按当前账户套餐使用，不自动升级付费计划；实际网络体验与并发容量仍需实测。
